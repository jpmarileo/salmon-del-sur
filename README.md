# Salmón del Sur

Sitio web de práctica para e-commerce de salmón fresco y ahumado, con soporte de idiomas y enfoque en SEO internacional.

Proyecto hecho con HTML, JavaScript y Tailwind CSS. Pensado para correr en SPCK y publicarse con GitHub Pages.

## Qué incluye

- Página de inicio, productos, nosotros, FAQ y contacto
- Cambio de idioma: **ES-CL**, **ES-AR** y **EN**
- Precios y WhatsApp distintos según región
- Etiquetas `hreflang` para SEO internacional
- Diseño mobile-first
- Llamadas a la acción para pedido por WhatsApp

## Tecnologías

- HTML5
- JavaScript (Vanilla)
- Tailwind CSS (CDN)

## Estructura

index.html
app.js
README.md

## Cómo abrirlo en local o SPCK

1. Crea un proyecto en SPCK.
2. Copia `index.html` y `app.js`.
3. Abre `index.html` y dale Run / Preview.
4. Prueba los botones **CL / AR / EN**.

Necesitas internet en el preview para que cargue Tailwind.

## Cómo publicarlo en GitHub Pages

1. Sube los archivos a un repositorio público.
2. Ve a **Settings → Pages**.
3. Source: `Deploy from a branch`.
4. Branch: `main`.
5. Folder: `/ (root)`.
6. Guarda y espera 1 o 2 minutos.

## Personalizar

En `app.js` puedes cambiar textos, precios y números de WhatsApp.

## Notas

Este sitio es un ejercicio de marketing digital y frontend. No es una tienda real en producción.
